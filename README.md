# SW4DX_OriginPack_v1.0.0
유랑연무의 이야기와 동료 이벤트를 확장하고, 장수전·록온·아군 지휘를 함께 즐길 수 있도록 묶은 통합 모드입니다.
# 전국무쌍4 DX 오리진팩 1.0.0

유랑연무의 이야기 확장부터 전투 AI·록온·아군 지휘까지 함께 사용할 수 있는 오리진팩을 공개합니다. **한글패치가 설치된 Steam Windows 64비트판 전국무쌍4 DX**를 기준으로 합니다.

## 포함 콘텐츠

**유랑연무 오리진**

역사 본편 20장·외전 11편, 55명 무쌍무장 대화와 파트너별 후일담, 클론 열전 178종, 일반 미니 이벤트 300편과 수제 단편·연작을 담았습니다. 축국·술대결 등 선택지 미니게임, 「히타치의 불사조」, 천하인 연작과 엔딩롤도 함께 즐길 수 있습니다.

20명에게는 인연 전장이 추가됩니다. 해당 무장의 **인연도 5 스토리까지 감상**하면 그 무장 모델과 푸른 천수각 표시가 필드에 등장합니다. 기존 여정에서 이미 조건을 채운 무장도 한 전장씩 출현합니다. 돌입·클리어 회화, 상황·역사 나레이션과 가보 중복 분기를 구성하고 대사와 몸짓을 검수했습니다. 발판은 기존 역사전투의 생성·접촉·효과·혼잡 처리를 공유합니다. 노부나가·나가마사·히사히데의 황금술잔 단편과 짧은 감상 선택도 포함합니다.

설정 파일은 `SW4Origin/SW4DX_ChronicleEvent.ini`입니다. 일반 전투 회화, 미니 이벤트, 무장 문답을 고르고 일반 이벤트의 발동률·종류별 비율·재감상을 설정할 수 있습니다.

**전투 특이점**

NPC 장수의 공격 연계·추격·가드 대응·회피·살진·승하마·협공 판단을 확장합니다. 플레이어 대응 QTE와 일반 무쌍 얼굴 연출, 화승총·기마·폭탄 부대 전법을 함께 제공합니다.

`SW4DX_Singularity.ini`에서 적 무쌍의 확률·대기·피해, 차지 경직 저항·발광, 회피 확률과 전법·연출 사용 여부를 조절할 수 있습니다. **신속 Y / 영기 공격 A / 회피 후 반격 A / 무쌍 B**의 사용 여부와 입력 시간을 각각 설정합니다. 동봉 기본 입력 시간은 Y/A 1초, B 2초이며 허용 범위는 150~10000ms입니다. 장수별 스타일 편집 표와 중지된 병사 기능·시험용 옵션을 정리하고 한글 주석을 붙였습니다.

**록온**

적 장수와 특수 대상을 선택하고 카메라로 추적합니다. R2 또는 기본 V 키를 짧게 눌러 대상 선택·변경, 약 0.28초 눌러 해제합니다. 일반 닌자·부하가 잘못 선택되는 경우를 줄이고 밀정·밀정대장은 유지했습니다.

`SW4DX_LockOn.ini`에서 특수 대상 포함, 마크·높이, 방어 방향 보정, 카메라 전환 시간과 키보드 키를 설정할 수 있습니다.

**커맨드 센터**

기존 명령창에서 다른 아군 장수에게 대기·호위·공격을 지시하고 선택한 장수를 잠시 조종할 수 있습니다. L2/R2로 장수 선택, X로 사용자 명령 취소, 명령창 Tab으로 임시 조종, 일반 전투 Tab으로 원래 캐릭터에 복귀합니다. 사용자 명령과 원작 별도 임무를 구분해 표시합니다.

`SW4DX_AlliedOrders.ini`의 `[AlliedOrders] Enabled`로 사용 여부를 설정합니다.

**적 호전성**

무쌍무장·클론무장·대상 병종에 기본 AI 강도를 배분하는 기존 성향별 v9를 포함합니다. 같은 템플릿을 쓰는 아군에도 적용됩니다. 별도 사용자 INI는 없습니다.

## 이전 공개 모드에서 달라진 점

- **오리진 1.1.1 대비:** 인연 전장 20편, 가보 중복 회화, 대사·몸짓 보완, 황금술잔 단편과 여정·슬롯 연결 개선을 반영했습니다.
- **전투 특이점 1.2.0 대비:** 플레이어 QTE·전법·일반 무쌍 연출과 클론 무쌍 확장을 추가하고, 대응 종류별 스위치·시간 설정을 마련했습니다.
- **록온 1.2.1 대비:** 무쌍 시작 중 방향 처리, 부하·일반 닌자 대상 제외와 최신 특이점 연동을 보완했습니다.
- **커맨드 센터 1.0.1 대비:** 목록의 반복 조회를 줄이고 임시 조종·파트너 전환·취소·메뉴 입력 처리를 보완했습니다.
- **적 호전성:** 기존 성향별 v9를 그대로 통합합니다.
- 공통 로더와 모듈 조합을 정리하고, 오리진·록온 시작 순서 및 오리진·커맨드 센터 초기 수정 경합을 보완했습니다.

## 설치·기존 진행 안내

게임 설치 폴더에 압축을 풀면 됩니다.

원작 세이브와 기존 여정·영입·인연·가보 기록을 초기화할 필요는 없습니다. 기존 슬롯 연결과 새 기록 형식은 합성 기록으로 승계를 검사했습니다. **일반 전투 회화 628종의 감상 표시만 수정된 회화를 다시 볼 수 있도록 한 번 갱신됩니다.**

설정은 게임 재시작 후 반영됩니다. 자세한 파일 설명과 모듈별 INI 가이드는 동봉 README를 확인하세요. 내부 동작·설치 검사를 수행했으며, 이번 통합본의 실제 게임 전체 플레이와 모든 GPU 연출을 확인한 단계는 아닙니다.
